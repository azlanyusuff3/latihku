**Artwork source:** [Twemoji](https://github.com/jdecked/twemoji) (original Twitter/Twemoji graphics; maintained by the Twemoji community).

**License for Twemoji SVG graphics:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). The original full license and notices are available in the Twemoji repository's [LICENSE-GRAPHICS](https://github.com/jdecked/twemoji/blob/main/LICENSE-GRAPHICS) file. Twemoji's software license is separate (MIT); the artwork uses **CC BY 4.0**.

**Changes:** Selected Twemoji vector graphics (67) have been copied as inline SVG path data into local files `cartoon-animals.js`, `cartoon-vehicles.js`, `cartoon-fruits.js`, `cartoon-nature.js`, and `cartoon-fun.js`. Their path art is preserved, but it is embedded into new, original illustrated square scenes generated by `puzzle-cartoons.js`: gradient skies, stylized landscapes, confetti, custom background and translated Malay labels. Artwork is rendered offline as a data URI. Nine further drawings (durian, submarine, Jupiter, Venus, Mars, xylophone, tambourine, ukulele and nasi lemak) are original LatihKu SVG shapes.

**Scope:** There are 76 separate cartoon puzzle subjects across five categories: animals, vehicles, fruit, nature and mixed. No photographic assets from `assets/general/*.webp` are loaded into the Kids Games gallery or jigsaw engine.

**Spot the Difference:** All paired scenes in `spot-scenes.js` and `spot-extra-scenes.js` are original LatihKu vector drawings. The first eight were created earlier; the additional twelve use original SVG paths. Neither source-game images nor code were copied.
