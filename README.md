# LatihKu Adventure v7 — Polished Tamagotchi Edition

Versi ini ialah fresh-start release. Apabila v7 dibuka pertama kali pada URL/repo yang sama, progress test versi lama akan direset **sekali sahaja**. Selepas fresh start itu, semua progress baru akan kekal seperti biasa.

## Fokus v7
- Home lebih simple: Mula Belajar, pilih tahap/subjek, Sahabatku, Misi, Kesilapan, Hadiah Harian.
- Konsep Dunia Saya dibuang daripada UI.
- Sahabatku ala tamagotchi: hunger, happiness, feeding, wardrobe dan outfit.
- Kedai menggunakan tab supaya tak serabut: Makanan / Outfit / Power-up.
- Daily gift +25 coin sekali sehari.
- XP, coin, streak, pet, outfit, mastery dan history kekal autosave dalam peranti.
- Bank soalan dan PWA offline dikekalkan.

## GitHub Pages
Extract ZIP dan upload **semua isi folder ini** ke root repository. `index.html` mesti berada terus pada root. Aktifkan GitHub Pages menggunakan branch `main` dan folder `/(root)`.
