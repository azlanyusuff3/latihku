# LatihKu KSSR v22

## Perubahan v22

- Laluan **Sekolah Rendah Agama (SRA)** kini tersedia untuk **Tahun 1 hingga Tahun 6**.
- Tahun 1–2 mengekalkan bank/generator SRA sedia ada.
- Tahun 3–6 mempunyai bank **LatihKu Original curated-first** bagi Tauhid, Fekah, Akhlak, Sirah, Tajwid, Jawi/Imlak/Khat dan Bahasa Arab.
- Selepas soalan curated yang belum dijawab habis, **AI SRA Generator offline** menghasilkan variasi baharu dan menggunakan anti-repeat memory yang sama seperti Smart Practice SK.
- Struktur T3–T6 diinspirasikan oleh format/bank awam SRA Selangor semasa (KSRA/JAIS-style), termasuk sumber sekolah awam SRA Al-Najah dan paparan struktur peperiksaan SRA Selangor 2025–2026. **Tiada set berbayar atau kertas pihak ketiga disalin ke dalam aplikasi.**
- SRA kekal diasingkan daripada Sekolah Kebangsaan.
- Buku Mewarna Pra sedia ada dikekalkan.
- Storage key lama dikekalkan (`latihkuStudyV10`) supaya progress sedia ada tidak reset.

## SRA ikut tahun

- Tahun 1–2: Tauhid, Fekah, Akhlak, Jawi, Bahasa Arab, Hafazan.
- Tahun 3–6: Tauhid, Fekah, Akhlak, Sirah, Tajwid, Jawi, Bahasa Arab.

## Offline

Gunakan **Tetapan → Download semua untuk offline** supaya pack SRA T3–T6 turut disimpan dalam cache data. Generator selepas bank habis berjalan sepenuhnya pada peranti tanpa API key.
